🏗️ Architecture du Pipeline

Twitter API→ Kafka Producer→ Kafka Broker→ Kafka Consumer→ CSV Storage→ Hive Analytics→ Snowflake→ Visualisation

🛠️ Technologies

🐍 Python 3.10 📨 Apache Kafka 🐝 Apache Hive ❄️ Snowflake 🐳 Docker 📊 Matplotlib 🐼 Pandas 🐦 Tweepy
